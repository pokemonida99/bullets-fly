# 《讓子彈飛》劇情整理（遊戲用）

> **主要依據：使用者提供的電影劇本電子書**《讓子彈飛一會兒》電影劇本（繁體中文版，共 184 場）。台詞照劇本原文，括號裡的數字是劇本場次。
> 輔助資料：百度百科〈讓子彈飛〉（造型設計段落）、官方「張牧之之麻匪兄弟連」人物關係圖、網路劇照。
> 使用者提供的參考影片（YouTube 0X711531Ip4）是街機《吞食天地 2》實況，當作**玩法參考**。
> 劇本與電影成片可能有出入；有疑問以使用者記憶為準。

## 時代與地點

- 劇本開頭字幕：**「北洋年間　南部中國」**。遊戲照這個寫，不寫「民國初年」。
- 委任狀落款「中華民國八年八月二十八日」、薩南康省主席巴青泰（29）。
- 鵝城：城門前有水、龜背地；城裡是騎樓街、縣衙（門口有乾隆年間設的冤鼓）、豔陽樓（講茶大堂、妓院）、黃家碉樓群（竹林掩映、二十棟碉樓、黃家大道鐵門）。
- 原著：馬識途《夜譚十記》之〈盜官記〉。

## 主線分幕（照劇本）

| 幕 | 場次 | 劇情 |
|---|---|---|
| 一、馬拉火車 | 1–27 | 十匹白馬拉兩節車廂（馬拉火車）。馬邦德（買官的騙子）、縣長夫人、湯師爺在車上吃火鍋唱歌，「鐵血十八星陸軍」護送。張牧之用長槍連開十槍打斷馬與車的連結，再甩兩把板斧卡進鐵軌，老二老三用馬槍槍托補砸，火車翻進河裡，湯師爺被火鍋燙死。張牧之戴九筒麻將面具，用鬧鐘逼問；馬邦德謊稱自己是師爺「姓湯」。 |
| 二、上任鵝城 | 28–32 | 麻匪換上鐵血十八星的軍服與官服進城。花姐帶女子太鼓隊迎接，城牆貼滿張麻子通緝令。胡萬、武舉人代黃四郎迎接，轎裡只放一頂禮帽。張牧之進城就槍斃五個「麻匪」（陸軍屍體戴上麻將面具）。黃四郎在碉樓頂用望遠鏡看，旁邊是替身楊萬樓。 |
| 三、站著把錢掙了 | 33–34 | 老湯說前任縣長把稅收到九十年後。張牧之：「我是想站著，還把錢掙了。」老湯：「敢問九筒大哥何方神聖？」張牧之：「鄙人，張麻子！」 |
| 四、冤鼓與武舉人 | 35–38 | 六子砍開長滿青藤的冤鼓，鼓滾上街追著賣涼粉的孫守義。戴墨鏡、一手拎兩隻燒鵝的武舉人把孫守義當球踢。升堂時武舉人說自己是「光緒三十一年皇上欽點的武舉人」，張牧之掏槍逼跪、打板子。張牧之在縣衙門口：「我來鵝城只辦三件事，公平！公平！還是他媽的公平！」 |
| 五、一碗涼粉 | 39–47 | 黃四郎安排胡萬在豔陽樓（講茶大堂）設局：「六爺，你吃了兩碗的粉，只給了一碗的錢。」六子剖腹證明只吃一碗，死去。張牧之打穿胡萬兩隻耳朵，老湯勸「殺人誅心」放人。兄弟們在六子墓前發誓報仇。 |
| 六、鴻門宴 | 48–56 | 黃四郎在碉樓設宴，用胡萬、孫守義、武舉人「三命抵一命」（假死），提議出一百八十萬剿匪。老湯：「酒一口一口喝，路一步一步走！步子邁大了，咔，容易扯著蛋！」黃四郎解釋「麻匪」：戴麻將面具的匪。 |
| 七、假麻匪夜襲 | 57–69 | 胡萬帶人戴麻將面具假扮麻匪，夜裡掃射縣長臥室，縣長夫人中彈身亡。張牧之揭開胡萬的面具，問出是黃四郎指使，胡萬隨後被打死。張牧之抱著夫人學老湯哭，騙過黃四郎。 |
| 八、綁票與替身 | 70–72 | 夫人葬禮上，戴九筒的「麻匪」（其實是老三，三筒是老四）綁走黃四郎與兩大家族。黃四郎現身：被綁的是替身。兩大家族的贖金到手。 |
| 九、散銀子 | 72–82 | 張牧之把錢裝進麻將面具做的小麻袋，從窗戶扔給窮人。老二老三把錢扔給花姐，被花姐識破身分。黃四郎讓家丁也扮麻匪去搶、去作惡，栽贓。老湯的山西前妻帶著一米八五的「八歲」兒子來要錢，張牧之給了兩顆鑽石。 |
| 十、四筒對四筒 | 83–90 | 雨夜，真假麻匪都戴四筒面具在街上對峙。死的六個假麻匪全是黃家的人。張牧之逼黃四郎出錢剿匪：「你給翻譯翻譯，什麼叫驚喜？」 |
| 十一、出城剿匪 | 91–126 | 張牧之對老湯說出身世：講武堂出身，追隨松坡將軍當手槍隊長的雙槍手。黃四郎拿馬邦德的照片揭穿張牧之，老湯改口說張牧之是外甥（「三舅」）。剿匪大會上老湯喊「麻匪，任何時候都要剿！不剿不行！」出城後遭臉上燙了麻子的「假麻子」伏擊，兄弟們用口哨傳令反擊，老二吊在索道上中彈墜潭。假麻子供出殺過五任縣長；老湯趕車奔山西救子，踩到黃四郎的地雷身亡。麻將面具全部燒掉。 |
| 十二、殺四郎，搶碉樓 | 127–178 | 張牧之帶萬民傘回城，宣布三天內斬黃四郎。先撒銀子、再撒槍，百姓都交回黃家。張牧之開槍打馬：「讓子彈飛一會兒！」百姓的槍聲終於響起。「槍在手，跟我走！」「殺四郎！」「搶碉樓！」——最後只有一群鵝跟著；「誰贏，他們幫誰！」四個人對鐵門打了一夜。老三花姐抓回替身，張牧之當街斬了替身，百姓以為黃四郎已死，在武舉人帶頭下衝進碉樓。 |
| 十三、結局 | 179–184 | 張牧之與黃四郎抽菸對談：「沒有你，對我很重要。」黃四郎在碉樓頂拋出禮帽，碉樓爆炸。老三老四老五老七騎自行車帶花姐去上海浦東。張牧之一人一馬出城，頭戴那頂禮帽，跟著馬拉火車的方向而去。 |

## 美術上致敬電影的元素

- **麻將面具**：麻匪戴麻將面具（「麻匪」的麻是麻將的麻），張麻子本人是**九筒**；黃四郎派的假麻匪也戴麻將面具冒充。遊戲裡的假麻匪戴九筒紙袋面具，倒地時面具會掉。
- **馬拉火車**：十匹白馬拉兩節車廂——標題畫面；結局張牧之一人一馬跟著火車走。
- **燒鵝**：武舉人登場時一手拎兩隻燒鵝——遊戲裡打倒武舉人會掉兩隻燒鵝（補血）。
- **涼粉、銀元**：涼粉案；麻匪把銀子裝進麻將面具做的小麻袋往窗戶裡扔。
- **鵝城、黃府碉樓、騎樓街**：關卡背景；城門匾額「鵝城」、碉樓鐵門「黃府」。
- **鐵血十八星軍服**：麻匪進城換上的軍服——大哥的深藍立領制服。
- **雙槍**：張牧之是松坡將軍的手槍隊長、雙槍手——大哥用雙槍。老二老三用馬槍槍托——二哥用步槍槍托打人。
- **大聲公**：老湯在縣衙門口、剿匪大會上慷慨演講。
