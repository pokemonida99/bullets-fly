# 角色設計（遊戲版）

**造型照電影劇照**：髮型、鬍子、衣服、配件、武器都照片中的樣子畫，不自己加（v0.1 第一稿有自創造型，已依使用者要求全部重畫）。
臉用 16-bit 像素畫風呈現，不做寫實真人臉。能力、招式依遊戲需要調整。

## 操作（全角色共通）

| 動作 | 鍵盤 | 手把 | 手機 |
|---|---|---|---|
| 移動（上下＝往裡／往外走） | 方向鍵／WASD | 十字鍵／左搖桿 | 左搖桿 |
| 攻擊（連按四段連打） | J／Z | A | 攻 |
| 跳（跳中按攻擊＝跳躍攻擊） | K／X | B | 跳 |
| 招式一（各人專屬，不耗血） | L／C | X | 招一 |
| 招式二（護身招，打中敵人會扣自己一點血） | I／V | Y | 招二 |
| 超必殺（怒氣滿才能放） | 空白鍵／O／B | RB | 超 |
| 跑步 | 連按兩下 → 或 ← | | 搖桿快推兩下 |
| 衝刺攻擊 | 跑步中按攻擊 | | |
| 抓人／摔 | 走到敵人身上自動抓住；按攻擊＝膝撞，按住反方向＋攻擊＝往後摔 | | |
| 暫停 | Esc／P | Select | START |

- **怒氣**：打人、被打都會累積，滿了按超必殺。
- **招式二扣血**：跟《吞食天地》一樣，護身招打中才扣，被包圍時用來脫困。
- **補血**：打破酒罈、木箱會掉出「燒鵝」（大補）、「涼粉」（小補）、「銀元」「金條」（加分）。

## 試玩版可選（5 位）

| 角色 | 定位 | 連打 | 招式一 | 招式二 | 超必殺 |
|---|---|---|---|---|---|
| **張牧之（張麻子）** | 平衡型・雙槍 | 左拳 → 槍托 → 前踢 → 迴身肘 | **雙槍連射**：兩發子彈，穿透一人 | **旋身雙槍**：原地旋轉朝兩側開槍 | **讓子彈飛一會兒**：朝天開槍，子彈停在空中，一會兒後落到每個敵人身上 |
| **老二** | 力量型・步槍 | 槍托戳 → 橫掃 → 前踢 → 槍托下砸（擊倒） | **步槍狙擊**：單發重彈，穿透三人並擊倒 | **槍托旋風**：抓槍管甩一圈 | **連環快槍**：三輪排槍，一次打上中下三條線 |
| **老三** | 速度型・快槍 | 直拳 → 槍柄反打 → 旋踢 → 膝撞 | **快槍三發**：扇形三發，上中下都打得到 | **側翻踢**：翻身往上踢 | **閃身連射**：一瞬間閃到每個敵人身邊開槍 |
| **六子** | 投技型・蠻力 | 直拳 → 勾拳 → 雙拳槌 → 肩撞 | **蠻牛頭槌**：低頭衝刺撞飛 | **旋風臂**：張開雙臂原地轉 | **大地震腳**：用力一跺，地上的敵人全部震倒 |
| **老湯** | 高難度・大聲公（挑戰用：最弱、要靠撒銀元和大聲公） | 大聲公戳 → 拍 → 亂踢 → 敲頭 | **撒銀元**：從袖子掏銀元丟出去 | **大聲公**：先抱頭蹲下躲攻擊，再對大聲公大吼，聲波把人震倒 | **天降橫財**：喊「鵝城的父老鄉親們」，把錢撒上天，敵人全跑去撿、愣住 |

抓人後的摔法：張牧之過肩摔、老二單手甩、老三跳馬翻摔、六子大背摔（傷害最高）、老湯推一把（最弱但推最遠）。

## 老四、老五、老七（v0.4 加入）

| 角色 | 定位 | 跟別人最不一樣的地方 | 招式一 | 招式二 | 超必殺 |
|---|---|---|---|---|---|
| **老四** | 遠距離型・斗笠 | **普通攻擊就是開槍**（點射兩發→雙手重射，可擊倒）；敵人貼身時才自動改用槍托和踢；血最少（85） | **斗笠飛盤**：甩出斗笠，飛出去會轉回來，去回都打得到；斗笠回到手上才能再丟 | **後跳射擊**：往後跳開、空中連開兩槍（拉開距離用） | **一槍一個**：準星一個一個鎖定畫面上的敵人，每人一槍 |
| **老五** | 耐打型・吹哨號令 | **血最多（140）、霸體**：出招時被打不會中斷（被擊倒招例外）；動作最慢 | **吹哨傳令**：吹哨叫一個兄弟從身後衝進來，整條線上的敵人都被撞倒 | **哨音震**：尖銳的哨音把周圍的敵人震暈（頭目只暈一下）；不扣血 | **總攻**：長哨一吹，兄弟們分四條線一起衝過整個畫面 |
| **老七** | 反擊型・近身無敵 | **按住招式二擺「被動」架勢**：正面攻擊（拳腳、子彈）全部擋下，擋到的瞬間自動衝出去反擊；背後挨打一樣會受傷 | **雙槍連轟**：雙槍連開兩輪，前方四條線都打得到（劇本第 102 場） | **被動**（按住）：擋＋自動反擊 | **我喜歡被動**：約 5 秒無敵，靠近的敵人會被自動反殺 |

台詞出處：老四「如果是我，不會有人活著來告狀」（80）、「殺四郎！」（160）；老五「總攻！」（115 的哨音）、「搶碉樓！」（160）；老七「我喜歡被動」（80）、「大哥我到了！」（106）。
劇照造型：老四光頭、米色立領短褂、頭戴斗笠（第 105 場甩斗笠）；老五短捲髮、鬍渣、黑皮夾克配白襯衫、脖子掛哨子；老七短髮、深色立領短褂、雙槍、掛哨子。
