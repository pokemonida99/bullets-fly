# 角色設計（遊戲版）

**造型照電影劇照**：髮型、鬍子、衣服、配件、武器都照片中的樣子畫，不自己加（v0.1 第一稿有自創造型，已依使用者要求全部重畫）。
臉用 16-bit 像素畫風呈現，不做寫實真人臉。能力、招式依遊戲需要調整。

## 操作（全角色共通）

| 動作 | 鍵盤 | 手把 | 手機 |
|---|---|---|---|
| 移動（上下＝往裡／往外走） | 方向鍵／WASD | 十字鍵／左搖桿 | 左搖桿 |
| 攻擊（連按四段連打） | J／Z | A | 攻 |
| 跳（跳中按攻擊＝跳躍攻擊） | K／X | B | 跳 |
| 招式一（各人專屬，不耗血） | L／C | X | 招一 |
| 招式二（護身招，打中敵人會扣自己一點血） | I／V | Y | 招二 |
| 超必殺（怒氣滿才能放） | 空白鍵／O／B | RB | 超 |
| 跑步 | 連按兩下 → 或 ← | | 搖桿快推兩下 |
| 衝刺攻擊 | 跑步中按攻擊 | | |
| 抓人／摔 | 走到敵人身上自動抓住；按攻擊＝膝撞，按住反方向＋攻擊＝往後摔 | | |
| 暫停 | Esc／P | Select | START |

- **怒氣**：打人、被打都會累積，滿了按超必殺。
- **招式二扣血**：跟《吞食天地》一樣，護身招打中才扣，被包圍時用來脫困。
- **補血**：打破酒罈、木箱會掉出「燒鵝」（大補）、「涼粉」（小補）、「銀元」「金條」（加分）。

## 試玩版可選（5 位）

| 角色 | 定位 | 連打 | 招式一 | 招式二 | 超必殺 |
|---|---|---|---|---|---|
| **大哥 張麻子** | 平衡型・雙槍 | 左拳 → 槍托 → 前踢 → 迴身肘 | **雙槍連射**：兩發子彈，穿透一人 | **旋身雙槍**：原地旋轉朝兩側開槍 | **讓子彈飛一會兒**：朝天開槍，子彈停在空中，一會兒後落到每個敵人身上 |
| **二哥** | 力量型・步槍 | 槍托戳 → 橫掃 → 前踢 → 槍托下砸（擊倒） | **步槍狙擊**：單發重彈，穿透三人並擊倒 | **槍托旋風**：抓槍管甩一圈 | **連環快槍**：三輪排槍，一次打上中下三條線 |
| **三哥** | 速度型・快槍 | 直拳 → 槍柄反打 → 旋踢 → 膝撞 | **快槍三發**：扇形三發，上中下都打得到 | **側翻踢**：翻身往上踢 | **閃身連射**：一瞬間閃到每個敵人身邊開槍 |
| **六子** | 投技型・蠻力 | 直拳 → 勾拳 → 雙拳槌 → 肩撞 | **蠻牛頭槌**：低頭衝刺撞飛 | **旋風臂**：張開雙臂原地轉 | **大地震腳**：用力一跺，地上的敵人全部震倒 |
| **湯師爺** | 技巧型・大聲公 | 大聲公戳 → 拍 → 亂踢 → 敲頭 | **撒銀元**：從袖子掏銀元丟出去 | **大聲公**：先抱頭蹲下躲攻擊，再對大聲公大吼，聲波把人震倒 | **天降橫財**：喊「鵝城的父老鄉親們」，把錢撒上天，敵人全跑去撿、愣住 |

抓人後的摔法：大哥過肩摔、二哥單手甩、三哥跳馬翻摔、六子大背摔（傷害最高）、湯師爺推一把（最弱但推最遠）。
